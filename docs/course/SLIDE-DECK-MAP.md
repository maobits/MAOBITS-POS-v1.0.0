# Mapa de diapositivas

Cada HITO tiene 7 diapositivas base. Con 15 hitos se obtiene un esqueleto de **105 escenas** antes de añadir retos, quizzes y laboratorios.

1. Problema / necesidad.
2. Modelo mental visual.
3. Contrato de la pieza.
4. Código incremental.
5. Laboratorio o simulación.
6. Ensamblaje con el producto.
7. Checkpoint y transferencia.

Los manifiestos JSON pueden ser consumidos posteriormente por un generador `.maobits` para crear outline, escenas y navegación sin inferir nuevamente la arquitectura.
