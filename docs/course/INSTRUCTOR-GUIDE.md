# Guía del instructor

Cada hito tiene siete escenas: necesidad, concepto, contrato, código, simulación, ensamblaje y checkpoint. Evita revelar el código completo antes de que el estudiante comprenda el problema.

Modos sugeridos:

- **CALCO:** ghost code solo de la nueva pieza.
- **COMPLETAR:** huecos controlados en la pieza nueva.
- **AUTÓNOMO:** contrato y pruebas, sin solución anticipada.

Al ensamblar, conservar los módulos anteriores sin reescribirlos. Si una pieza obliga a modificar masivamente otra, revisar el contrato arquitectónico antes de continuar.
