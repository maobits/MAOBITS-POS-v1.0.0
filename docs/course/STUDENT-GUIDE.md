# Guía del estudiante

Trabaja un hito a la vez. Antes de escribir código debes poder explicar: qué problema resuelve la pieza, qué recibe, qué entrega y de qué piezas depende.

Para practicar de forma aislada, exporta el módulo indicado por el instructor con `npm run course:export -- <moduleId>`. El bundle generado es una copia didáctica; el código canónico permanece en la raíz del proyecto.
